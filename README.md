# Images pour la SAE3 (2026/2027)

Ce dépôt Git est destiné uniquement à notre projet étudiant de développement d'une plateforme de location saisonnière de type Airbnb (un fork du projet est à venir).

## Utilisation

Sur le serveur de développement ou de production, placez-vous dans `~/sae/` et copiez le script `reset_housing_images.sh` s'il n'est pas déjà présent :

```bash
scp reset_housing_images.sh <user>@<ip-serveur>:~/sae/
```

Une fois le script en place dans `~/sae/`, exécutez-le :

```bash
./reset_housing_images.sh
```
